# 真实产出 demo

这里是 `lexicon-atelier` **实际跑出来的产物**，不是示意，不是手写文档。用 [`../input.md`](../input.md) 那份 ADC 行业速览当输入，完整走了一遍流程。

## 先看这个

**`preview.html`** —— 用浏览器打开它。

页面右上角有一个「复制到公众号」按钮。点一下，它会把整篇文章的**渲染结果**（带全部样式的富文本）复制到剪贴板；再到公众号编辑器里按 `Ctrl/⌘+V` 粘贴，版式原样带过去。

> **注意**：GitHub 上点开 `.html` 只会显示源码，看不到效果。你需要把仓库下载到本地，用浏览器打开这个文件。

## 为什么不能直接复制 `article.html`

`article.html` 是真正被复制的**正文片段**（纯 `<section>`，没有 `<!DOCTYPE>`、`<html>`、`<head>`）。它是给程序用的中间产物，也是合规校验的对象。

**不要从文本编辑器里复制它，再粘到公众号**——那样粘过去的是满屏 `<section style="...">` 标签，不是文章。

能粘贴到公众号的，永远是**浏览器渲染之后的富文本**。所以要经过 preview 页转一道手：浏览器渲染 → 复制渲染结果 → 粘贴。

## 文件说明

| 文件 | 是什么 |
|---|---|
| `preview.html` | **入口**。带复制按钮的预览页，浏览器打开后一键复制 |
| `article.html` | 干净正文片段（纯 `<section>`），可粘贴内容的真实载体，也是校验对象 |
| `术语词典.md` | 术语词典的人类可读版 |
| `术语词典.json` | 术语词典的结构化版，可被程序读取与复用 |
| `正文源文.md` | 生成文章用的源文（文章正文来自这里） |
| `术语数据.py` | 术语数据文件——**换文章时主要就是改这个** |

## 这份 demo 的产出规模

| 项 | 值 |
|---|---|
| 术语条数 | 16 条（A1–E3，覆盖技术 / 指标 / 监管 / 产业四组） |
| 文章结构 | 10 节（00–09），正文 5 章 |
| 两栏行 | 8 行（术语首次出现处自动分栏） |
| 续排块 | 3 个（右栏装不下的术语移到段后，两列并排） |
| 正文徽标 | 16 枚，与右栏术语条一一对应 |
| 平台校验 | 0 ERROR / 0 WARNING |

规模比真实项目小（真实项目通常 30–45 条术语），但流程完全一样，两栏、续排、编号对应、附录这些机制都真实跑到了。
