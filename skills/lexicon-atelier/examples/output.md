# 产出物示例（格式说明）

> **本文件为合成示例。** 演示的是 `lexicon-atelier` 处理 [`input.md`](input.md) 之后的产出**形态**。示例只展开 8 条词条以保持可读。

> ⚠️ **想看真东西去 [`demo/`](demo/) 目录。** 本文件是格式说明，用 Markdown 写方便你在 GitHub 上直接读；但它是"说明书"，不是产出物本身。
>
> `demo/` 里放着**实际跑出来的**完整产物：浏览器打开 `demo/preview.html`，点右上角「复制到公众号」，就能把带完整版式的文章粘进公众号编辑器。产出物必须是 HTML 而不是 Markdown——原因与操作方法见 [`demo/README.md`](demo/README.md)。

## 二、术语词典一览表

| 编号 | 中文名 | 英文名 | 分类 | 一句话定义 | 原文出现位置 |
|---|---|---|---|---|---|
| A1 | 抗体偶联药物 | Antibody-Drug Conjugate, ADC | 技术 | 用连接子把单克隆抗体与细胞毒小分子拼在一起、靠抗体导向在肿瘤局部释放毒素的药物形态 | 导言 |
| A2 | 连接子 | Linker | 技术 | 连接抗体与有效载荷的化学桥，决定毒素在何时何地释放 | 导言 |
| A3 | 有效载荷 | Payload | 技术 | ADC 中真正杀死细胞的那部分——通常是高活性细胞毒小分子 | 导言 |
| A4 | 药物抗体比 | Drug-to-Antibody Ratio, DAR | 技术 | 平均每个抗体分子上偶联的毒素数量，是决定疗效与耐受性的核心工艺参数 | 一、关键指标 |
| A5 | 旁观者效应 | Bystander Effect | 技术 | 毒素从靶细胞渗出、杀伤邻近抗原阴性细胞的现象，对实体瘤既可能是优势也可能是毒性 | 一、关键指标 |
| A6 | 治疗窗 | Therapeutic Window | 技术 | 有效剂量与毒性剂量之间的安全区间；ADC 的疗效竞争本质上是治疗窗的竞争 | 一、关键指标 |
| C1 | 突破性疗法认定 | Breakthrough Therapy Designation | 监管 | 早期临床显示显著优势即可申请的加速通道，换取与审评机构更密集的沟通 | 四、监管 |
| E1 | 许可输出 | License-out | 产业 | 把早期管线授权给大型药企，换取首付款、里程碑付款与销售分成的变现方式 | 三、商业模式 |

## 四、成稿文章结构

术语以左右两栏的形式嵌在正文里，编号与右栏一一对应。

```
头图卡      系列标识 | 2026 · 10
            抗体偶联药物 · 靶向与毒素之间的工程学
            术语 16 条 · 数据表 0 张 · 参考文献 6 条

目录卡      00 核心观点 … 09 参考文献

00 核心观点 摘要卡（核心判断 / 关键风险 / 验证信号）
01 技术路线  ← A1 抗体偶联药物、A2 连接子 在此首次出现，切两栏
02 关键指标  ← A4 药物抗体比 在此首次出现，切两栏
03 产业链    ← 偶联 CDMO 相关词条在此首次出现
04 商业模式  ← E1 许可输出 在此首次出现，切两栏
05 监管路径  ← C1 突破性疗法认定 在此首次出现，切两栏
06 风险提示 编号风险卡 01–05
07 结语
08 附录：术语详解   16 条完整词条，与正文章节编号一一对应
09 参考文献
署名 + 结尾互动区
```

## 五、两栏版式示意

术语第一次出现的那一段，正文自动变成左右两栏。以下是渲染后的结构（示意）：

```
┌──────────────────────────────────┬─────────────────────────┐
│ 业内评估一条 ADC 管线，绕不开      │ 本段术语 · 2 条          │
│ 三个指标：药物抗体比 ① ——           │ ─────────────────────── │
│ 平均每个抗体上挂了多少个毒素        │ ① 药物抗体比 [附录 A4]   │
│ 分子。太低打不死细胞，太高则        │ Drug-to-Antibody Ratio  │
│ 抗体容易聚集、清除加快。           │ [技术] 平均每个抗体分子… │
│                                  │ 是什么/有什么作用/如何…  │
│                                  │ ─────────────────────── │
│                                  │ ② 旁观者效应 [附录 A5]   │
│                                  │ Bystander Effect        │
│                                  │ [技术] 毒素从靶细胞渗出… │
└──────────────────────────────────┴─────────────────────────┘
```

要点：

- 正文里的术语带**橙色下划线 + 橙色编号徽标**，徽标数字与右栏条目一一对应
- 编号按术语在正文中**出现的先后**排，不是按词典编号排
- 右栏装不下的术语，自动续排到该段之后，两列并排，栏头写「本段术语（续） · 3—8 条」
