# AI 作品集 · lainie-w

这里放我做的 AI 技能（skill）。每一个都是为了解决我自己在实际工作里遇到的一个具体问题，不是演示 demo。

## 我解决的问题

**长文里的专业术语，读者读到就卡住。**

行业报告、深度研究这类内容，术语密度很高。读者遇到不认识的词只有两个选择：硬着头皮读下去，或者翻到文末的术语表——翻过去就回不来了，阅读节奏断掉。

我做的 `lexicon-atelier` 换了个做法：把术语词典**拆开，放到术语第一次出现的那个段落旁边**，用左右两栏呈现。左边读正文，右边立刻看到解释，不需要跳转、不需要记忆。同时产出一份结构化的术语词典文件，可复用、可检索、可给同事。

一句话：**让专业内容保持专业，但不让读者卡住。**

## 怎么用

每个 skill 目录里有三样东西：

- **`README.md`** —— 给人看的：这个技能解决什么问题、怎么用、有什么限制
- **`SKILL.md`** —— 给 AI 看的：技能定义与执行步骤（Claude Code Skill 格式）
- **`examples/`** —— 一组完整的输入输出示例，用合成数据写成

想直接用：把 `skills/<名称>/SKILL.md` 放进你的 Claude Code 技能目录，然后描述你的任务即可，技能会按里面的步骤执行。

想先看效果：翻对应 skill 的 `examples/`，先看 `input.md` 再看 `output.md`。
